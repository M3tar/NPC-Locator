# 阶段 3：地点本地化、GMCM 与追踪栏验证

本轮同时完成阶段 2 收尾和阶段 3 首个可测试版本：主机 F3 查询、地点名回退、立即刷新、开始/取消追踪、GMCM 配置以及单 NPC 追踪栏。

## 更新

完全退出游戏和 SMAPI，在 Windows 项目目录构建并更新：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Windows.ps1 -Install -UpdateExisting
```

联机测试时主机与农场助手应安装同一次构建。

## 构建与加载

1. 确认构建成功，且没有本 Mod 的 C# 错误。
2. 启动 SMAPI，确认本 Mod 正常加载。
3. 安装了 GMCM 时，在设置列表中确认出现“NPC 定位器”；没有 GMCM 时，本 Mod 也必须正常加载。

## 地点名回归

1. 在中文游戏中查询塞巴斯蒂安。
2. 实时地点和日程中的 `SebastianRoom` 应显示为“塞巴斯蒂安的房间”。
3. 木匠的商店、山等已有游戏显示名的地点应继续使用游戏中文名称。
4. 未识别的自定义地图应明确显示为“自定义地点：内部名”，不能伪装成已翻译地点。

## 查询窗口

1. 分别在单人档、联机主机和联机农场助手按 F3 打开窗口。
2. 查询一名 NPC，测试“立即刷新”。
3. 测试“开始追踪”和“取消追踪”。
4. 日程超过 6 条时，在右侧区域滚动查看其余条目。
5. 用手柄测试方向键选择、A 查询、X 刷新、Y 追踪/取消、B 关闭。

## 追踪栏

1. 开始追踪一名与玩家不在同一地点的 NPC，然后关闭查询窗口。
2. 确认追踪栏显示本地化 NPC 名、当前位置与下一站。
3. 等待游戏时间变化，确认位置自动刷新且控制台不刷普通查询日志。
4. 玩家换地图后确认会刷新一次。
5. 与 NPC 进入同一地图，确认显示八方向文字和约多少格；不同地图时不显示方向距离。
6. 睡觉进入下一天，确认手动追踪仍保留并刷新。
7. 返回标题或农场助手与主机断开，确认追踪状态清除。

## GMCM

1. 将打开按键从 F3 改为其他键并保存，确认立即生效。
2. 切换追踪栏显示、位置、透明度、下一站和方向距离选项。
3. 在主机关闭远程查询或单项共享，确认农场助手得到明确错误；主机自己的本地查询仍可使用。
4. 使用 GMCM 的恢复默认值功能，确认所有选项恢复且无需重启。

## 回传信息

- Windows 构建的完整警告与错误；
- 塞巴斯蒂安查询窗口截图；
- 主机与农场助手各一张追踪栏截图；
- 使用的分辨率和 UI 缩放；
- GMCM 改键是否立即生效；
- 双方 SMAPI 日志中的本 Mod 错误。
