# 阶段 2：F3 查询窗口验证

本轮加入第一个可交互查询窗口，用来验证菜单基础、搜索、列表、主机查询结果和中英文文本。追踪、任务提示和方向指引尚未加入。

## 更新

完全退出游戏和 SMAPI，在 Windows 项目目录构建并更新：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Windows.ps1 -Install -UpdateExisting
```

双方联机时，主机与非主机应安装同一次构建。

## 单人冒烟测试

1. 载入普通单人档。
2. 按 `F3` 打开窗口。
3. 在搜索框输入 `Pam`，确认列表过滤。
4. 点击 Pam，确认右侧显示实时位置和今日标准日程。
5. 清空搜索，滚动 NPC 列表并选择 Abigail。
6. 按 `Esc` 或右上角关闭按钮退出。

## 联机测试

1. 主机与非主机通过 SMAPI 进入同一存档。
2. 主机按 F3 时默认不打开窗口，这是静默主机的预期行为。
3. 非主机按 F3 打开窗口。
4. 让非主机停留在农场或农舍，查询不在当前地图的 Pam 与 Abigail。
5. 确认菜单显示内容与上一轮 `mnl_query` 主机权威结果一致。
6. 滚动 NPC 列表与日程，确认没有卡死、重叠或控制台错误。
7. 断开主机或只在客户端保留 Mod 时查询，确认窗口显示主机不可用，而不是永久停留在“正在查询”。
8. 打开窗口后应继续看到原游戏世界，不能替换成蓝色菜单背景；窗口本体应使用与 Lookup Anything 默认主题相同的游戏原生羊皮纸背景，不应出现白灰色填充或三段横向色带，仅选中行和鼠标悬停行允许局部高亮。
9. 确认窗口比上一版略矮但文字未裁切；右侧日程最多显示 10 行，左侧列表可继续用滚轮浏览。

## 回传信息

- Windows 构建的完整警告与错误；
- 单人档和非主机窗口截图；
- 搜索框是否能输入英文和中文；
- NPC 列表中是否出现明显的非 NPC/通用条目；
- UI 缩放比例、分辨率以及是否发生裁切；
- 双方 SMAPI 日志中的本 Mod 错误。
