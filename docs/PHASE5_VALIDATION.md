# 阶段 5：0.1.0 最终验收与打包

本清单使用同一个最终二进制包验收，不再混用历史阶段包。

## 1. 生成最终包

在 Windows 源码目录中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Windows.ps1 -Install -UpdateExisting -Package
```

非默认 Steam 库追加：

```powershell
-GamePath 'D:\SteamLibrary\steamapps\common\Stardew Valley'
```

预期结果：

- Release 编译成功；
- 当前电脑的 `Mods\NpcLocator` 安全更新；
- `dist\NpcLocator-0.1.0.zip` 生成；
- zip 顶层只有一个 `NpcLocator` 文件夹，其中包含 DLL、manifest、i18n 与说明。

## 2. 同版双方冒烟

1. 主机和农场助手删除旧的本 Mod 文件夹，各自解压同一个最终包到 `Mods`。
2. 确认双方 SMAPI 均识别 `NPC Locator 0.1.0`。
3. 主机与农场助手分别打开 F3，查询同一 NPC，对比实时地点、坐标与今日标准日程。
4. 农场助手追踪一名远端室内 NPC，等待至少两个游戏时间刻度，确认定时刷新。
5. 主机开始自己的手动/任务追踪，农场助手的查询不应弹出主机窗口或改变主机追踪。
6. 分别开始手动追踪和任务关联追踪，悬停追踪栏右上角 `×` 应显示“停止追踪”，背景应为与界面一致的棕金色而非白色；点击后追踪栏立即消失，点击不应穿透到游戏，送货任务本身不受影响且仍可从 F3 重新追踪。
7. 使用英文输入在 NPC 搜索框依次输入 `de`、`Emily` 和 `Elliott`，字母 `e` 不得关闭窗口；`Esc` 与 F3 仍应正常关闭窗口。
8. 游戏语言设为简体中文时，左侧人物名单应按中文拼音排列，例如“阿比盖尔”位于“哈维”之前、“潘姆”位于“亚历克斯”之前；缺少中文显示名的英文回退项位于中文姓名之后。切换英文后仍按英文显示名排列。

## 3. 安装组合边界

| 场景 | 预期 |
|---|---|
| 双方同版 | 完整查询和追踪 |
| 只有农场助手安装 | F3 可打开，远程查询明确提示主机不可用，不持续发送 |
| 只有主机安装 | 主机本地功能正常；未安装的农场助手无本 Mod 界面 |
| 协议不兼容 | 显示版本/协议不兼容，不使用过期结果 |

## 4. 主机共享与断线

1. GMCM 中分别关闭“允许远程查询”、“共享实时位置”和“共享今日标准日程”，农场助手应得到区分明确的拒绝状态。
2. 主机关闭远程共享时，主机自己的 F3 本地查询仍正常。
3. 农场助手追踪期间让主机退出，应停止远程等待/追踪，不得冻结或持续报错。
4. 重新连接后可重新手动选择追踪，旧请求的过期响应不得覆盖新结果。

## 5. 游戏状态与 UI 边界

- UI 缩放：75%、100%、125%（若游戏选项可用）；
- 视窗：窗口化与全屏；
- 手柄：方向键、A、X、Y、B 与左右肩键切换分页；
- 普通日、雨天、节日/事件、NPC 暂时不存在、无标准日程；
- 未解锁姜岛的 Leo：可列出，但应安全显示暂时无法定位；
- 任务：剧情交付、公告栏随机交付、同时多任务、完成、取消和过期。
- 追踪栏四个位置：关闭按钮始终位于卡片右上角，窗口边缘不裁切，点击区域与显示位置一致。
- 追踪栏三列布局：追踪乔治、艾芙琳或亚历克斯，确认类似“10:40 / 乔治、艾芙琳和亚历克斯的家 / 17,22”的下一站按“标签或时间 / 地点 / 坐标”对齐；坐标不得换行或与地点混淆，方向与距离应独立成行。坐标使用无底色的深棕文字并贴齐右侧，当前位置、下一站与方向行不应出现不同的背景块或特殊分隔线。极端长地点只截断地点列，悬停后应显示完整名称。
- 分别以 90% 和 100% 透明度，在明暗差异明显的地图区域观察追踪栏：中心应保持统一暖色，不应再出现固定的三段式横向明暗色带；切换透明度不得改变卡片尺寸和三列对齐，也不得因阴影透入框内而整体发暗。
- rc10 视觉对比：追踪栏应恢复接近原版背包/菜单的棕色像素边框与阴影，中心保持统一暖米黄色；不得出现 rc9 整张信纸裁切感，也不得恢复 rc8 的中心横向色带。
- 触发右下角送货任务提示：提示框应与追踪栏使用相同的原生菜单边框、暖色内层和外侧阴影，但保持完全不透明；“追踪目标”为较明显的棕金主按钮，“忽略此任务”为较淡的次按钮，两者悬停时不得出现白色背景。

## 6. 日志与卸载

1. 检查双方 SMAPI 日志，确认没有由 `NPC Locator` 产生的红色未处理错误。
2. 正常查询/追踪不应逐帧或每次刷新刷屏。
3. 备份存档后删除 `Mods\NpcLocator`，游戏与原存档应仍可正常加载。
