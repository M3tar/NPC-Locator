# 设计决策记录

## D-001 项目标识

- 状态：已确认
- 日期：2026-07-31
- 中文名称：联机 NPC 定位器
- 英文名称：Multiplayer NPC Locator
- 作者：Mercury
- UniqueID：`Mercury.MultiplayerNpcLocator`

## D-002 产品与发布策略

- 首版版本号为 0.1.0。
- 按未来公开发布标准组织代码、翻译和文档。
- 首版仅供私人联机内测，稳定后再决定是否发布到 Nexus Mods。

## D-003 Lookup Anything 关系

- 本项目是独立 SMAPI Mod。
- 不引用、修改或硬依赖 Lookup Anything。
- 主机与查询者安装本 Mod 即可；Lookup Anything 各自可选安装。

## D-004 联机数据模型

- 主机是 NPC 位置和日程的权威来源。
- 客户端发送结构化 NPC 查询请求，主机自动响应。
- 主机默认静默运行，不弹窗、不暂停、不改变 NPC 或任务。
- 主机首版使用三个总开关，不做逐玩家授权。

## D-005 查询与追踪

- 默认 F3 打开，可通过 KeybindList、GMCM 或配置文件修改。
- 同时追踪一个 NPC。
- 手动追踪跨游戏日保留，退出或重新载入后清除。
- 任务追踪在任务完成、取消或过期后取消。
- 同地图首版显示文字方向与距离；方向箭头后续增强。

## D-006 任务识别

- 首版识别标准物品交付任务。
- 发现任务后使用非阻塞角落提示询问是否追踪。
- 不强制覆盖当前追踪目标。
- 玩家任务内容只在本地解析，不发送给主机。

## D-007 兼容范围

- 最低支持 Stardew Valley 1.6.15。
- 目标 SMAPI 4.5.2，并尽力兼容后续 1.6.x。
- 首版正式支持原版 NPC。
- 自定义 NPC 仅做结构性兼容，不在缺少测试环境时承诺完整支持。
- 简体中文与英文同时交付。
- 首版基础支持手柄按键，完整手柄菜单导航后续完善。

## D-008 真实性与限制

- UI 严格区分“实时位置”与“今日标准日程”。
- 节日、剧情或脚本控制导致标准日程不可用时，不伪造预测。
- 接受 SMAPI 无法可靠检测所有第三方快捷键冲突的限制，以自由改键解决。

## D-009 主机主动查询

- 联机主机也可使用与农场助手相同的 F3 查询窗口、追踪栏和本地任务识别功能。
- 主机查询直接读取本机权威世界状态，不向联机通道发送自我请求，也不受 `AllowRemoteQueries` 等远程共享开关限制。
- “主机默认静默”仅指主机不会因农场助手的远程请求自动弹窗、暂停游戏或显示通知；不再表示禁止主机主动打开查询器。
- 单人、联机主机和联机农场助手共用相同界面与本地功能，只有查询数据来源不同。

## D-011 追踪栏快速停止

- 状态：已确认。
- 日期：2026-08-01
- 追踪栏右上角提供悬停可见反馈的 `×`，提示语义为“停止追踪”，而不是只隐藏追踪栏。
- 点击后清除当前追踪；若来自送货任务，只解除追踪关联，不修改或取消任务，玩家仍可从 F3 的任务分页重新追踪。
- 不根据 NPC 对话或交互自动结束追踪，避免误判玩家意图。
- 关闭按钮只在追踪栏实际显示且没有打开游戏菜单时接收鼠标点击，并拦截该点击以免穿透到游戏世界。

## D-012 中文人物名单排序

- 状态：已确认。
- 日期：2026-08-04
- 游戏语言为简体中文时，左侧人物名单使用固定 `zh-CN` 文化规则按本地化中文显示名的拼音排列，不依赖 Windows 系统语言。
- 缺少中文显示名、只能回退为英文内部名的角色保留在完整名单中，并排在中文姓名之后。
- 同音或文化比较结果相同时使用 NPC 内部名作为稳定排序键；其他游戏语言继续按本地化显示名排列。

## D-013 追踪栏结构化布局

- 状态：已确认。
- 日期：2026-08-04
- 采用方案 A：追踪栏使用固定的“标签或时间 / 地点 / 坐标”三列，当前位置与下一站各自绑定坐标。
- 方向和距离独立成行，不与当前或下一站坐标合并，避免语义混淆。
- 卡片优先使用较宽但仍紧凑的布局，并在较小视窗中自动收窄；极端长的自定义地点只截断地点列，悬停显示完整名称。
- 不再使用普通句子自动换行，坐标必须始终作为不可拆分的右对齐信息显示。
- 追踪栏固定首选宽度为 540 像素；所有信息行共用统一的羊皮纸表面，不为坐标添加单独底色，也不为方向行添加特殊分隔线。
- 追踪栏与 F3 查询窗口使用同一游戏原生 `LooseSprites/letterBG` 纹理；按卡片比例居中裁切，不使用会产生固定横向明暗带的 `drawTextureBox` 中心纹理。现有透明度设置继续生效。

## D-014 追踪栏原生菜单背景

- 状态：已确认试用，替代 D-013 中关于 `letterBG` 追踪栏背景的决定；三列布局及 540 像素宽度不变。
- 日期：2026-08-04
- 追踪栏改用原版背包/菜单风格：沿用 `drawTextureBox` 对应的游戏菜单纹理边角、边线与阴影。
- 不再拉伸九宫格的完整中心块；仅取同一纹理中心的稳定暖色像素铺满内层，以消除固定横向明暗色带，同时避免硬编码早期测试失败的偏白灰填充色。
- 背景所有部分只绘制一次并统一应用追踪栏透明度；信息行仍无独立底色。
- 右下角送货任务提示复用同一面板绘制组件，但保持完全不透明以确保临时决策信息清晰；“追踪目标”使用更明显的棕金主按钮，“忽略此任务”使用更淡的次按钮，均不使用白色悬停块。
