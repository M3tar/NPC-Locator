# 阶段 4 Windows 验证：送货任务识别

本轮只需更新需要使用任务提示的电脑。任务内容始终在当地玩家的电脑上读取，不会发送给主机。

## 1. 编译并更新

在源码包目录中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Windows.ps1 -Install -UpdateExisting
```

若脚本找不到游戏，在末尾加上：

```powershell
-GamePath 'D:\SteamLibrary\steamapps\common\Stardew Valley'
```

## 2. 剧情送货任务

用已经包含“作物研究”（给德米特里厄斯送甜瓜）的存档进行测试：

1. 进入存档后等待约 1 秒，屏幕角落应出现“发现送货任务”。
2. 确认标题、德米特里厄斯、甜瓜、数量和背包持有数均正确。
3. 点击“追踪目标”，追踪栏应开始查询德米特里厄斯。
4. 用 F3 手动改为追踪其他 NPC，再完成或删除该任务；手动追踪不应被自动停止。
5. 重新进入存档，再次选择任务追踪并完成/取消任务；若仍在追踪该任务目标，追踪应自动停止。

## 3. F3 送货任务分页与重新关联

1. 按 F3，确认窗口左上角有“NPC 查询”和“送货任务（数量）”两个分页。
2. 进入“送货任务”，选择“作物研究”，确认右侧显示目标、甜瓜、数量、背包持有数和期限。
3. 点击“追踪任务目标”，然后在“NPC 查询”分页手动改为追踪格斯。
4. 再次进入“送货任务”分页，重新点击“追踪任务目标”；应再次建立德米特里厄斯的任务关联追踪。
5. 在“NPC 查询”分页手动选择德米特里厄斯；这次应是手动追踪，任务完成时不应自动停止。
6. 在“送货任务”分页建立关联后，按钮应变为“取消任务追踪”，并可随时取消。
7. F3 窗口不关闭：点击追踪后，右侧底部应立即出现窗口内追踪卡片；任务追踪应显示任务名、NPC 和“正在获取当前位置”，随后更新为实际地点。
8. 切换到另一个分页或选择其他条目，当前追踪卡片应仍然可见。
9. F3 打开时屏幕角落不应同时绘制 HUD 追踪栏；关闭 F3 后，同一追踪信息应自动出现在配置的屏幕角落。

## 4. 忽略与去重

1. 对另一个送货任务点击“忽略此任务”。
2. 继续游戏至少 10 秒，该任务不应反复弹出。
3. 若同时有多个送货任务，忽略或追踪第一个后，下一个应在约 1 秒后显示。
4. 返回标题后重新载入存档，提示记录会重置；本 Mod 不把处理状态写入存档。

## 5. 公告栏随机送货任务

1. 接受一个标准物品交付任务。
2. 确认提示中的 NPC、物品、需要数量、背包持有数和剩余天数。
3. 完成、取消或等待过期，确认任务关联追踪会停止。

## 6. GMCM 与联机边界

1. GMCM 中关闭“识别送货任务”，提示应立即消失，且不再生成。
2. 重新开启后，尚未处理的活动任务可再次显示。
3. 联机主机和农场助手各自只看到自己任务日志中的提示。
4. 主机不应因农场助手的任务而出现提示或日志输出。

## 回传内容

- Windows 编译是否成功；
- 剧情任务和公告栏任务的提示截图；
- F3 窗口内的手动追踪卡片和任务追踪卡片截图；
- 点击“追踪目标”、“忽略此任务”及任务结束后的结果；
- SMAPI 红色错误（如果有）的完整文本。
