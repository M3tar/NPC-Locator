# Multiplayer NPC Locator

《星露谷物语》联机 NPC 定位器，由 Mercury 发起。

该 Mod 允许单人玩家、联机主机和农场助手查询 NPC 实时位置、今日标准日程并持续追踪任务目标。联机农场助手通过主机端提供的权威数据查询；主机直接读取本地权威数据。它独立于 Lookup Anything，不修改存档。

## 当前状态

- 阶段：阶段 2 查询窗口已通过核心验证；阶段 3 地点本地化、GMCM 与单 NPC 追踪栏已编码，等待 Windows 联机验证。
- 计划版本：0.1.0 私人内测版。
- 目标环境：Stardew Valley 1.6.15+、SMAPI 4.5.2、Windows 11。
- 唯一 ID：`Mercury.MultiplayerNpcLocator`。
