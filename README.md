# Multiplayer NPC Locator

《星露谷物语》联机 NPC 定位器，由 Mercury 发起。

该 Mod 允许非主机玩家通过主机端提供的权威数据，查询 NPC 实时位置、今日标准日程并持续追踪任务目标。它独立于 Lookup Anything，不修改存档。

## 当前状态

- 阶段：阶段 1 主机权威查询闭环已通过；阶段 2 F3 查询窗口首版等待 Windows 编译与界面验证。
- 计划版本：0.1.0 私人内测版。
- 目标环境：Stardew Valley 1.6.15+、SMAPI 4.5.2、Windows 11。
- 唯一 ID：`Mercury.MultiplayerNpcLocator`。
